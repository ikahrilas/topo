# Grant status records funding patterns, not causes

The founder-proxy asked for a status flag with values like "non-continued in 2025", "in litigation" and "reinstated". No public source flags these per Grant. The only per-Grant evidence is the USAspending funding sequence, and gaps there are routine: 95 Grants went unfunded in normal 2024. Court records name only about 11 Grants, the other members are sealed, and the case settled on private terms. We therefore record **Funding status** (continued, funded late, unfunded, reversed, not yet readable) for each Grant and Budget period, and **Lifecycle stage** as a separate field. A cause appears only as a cited note when a public source names the Grant's FAIN. A sticky **2025–26 disruption** marker carries what "reinstated" was meant to convey. Labelling every gap "non-continued" would claim causes we can't support, and the brief forbids inventing facts.

## Consequences

- "In litigation" is not a status value. Court-named Grants get a cause note instead.
- The disruption marker is not proof of a policy cut, and the one-pager must say so.
- If a per-Grant cause source becomes public (PACER exhibits, settlement terms, §524 notices to Congress), it feeds the cause notes. Funding status stays as it is.

Decided in [How is the 2025–26 status flag defined and sourced?](https://github.com/ikahrilas/topo/issues/9).
